# Go Authentication & Authorization System

This is a Go implementation inspired by copyparty's authentication and authorization system, using sqlc and SQLite.

## Features

- **Password-based authentication** with Argon2id hashing
- **Session management** with cryptographically secure session IDs
- **Fine-grained permissions** (read, write, move, delete, admin, etc.)
- **User and group management**
- **Cookie-based authentication**
- **Volume/resource-based access control**

## Architecture Overview

### Authentication Flow

1. User provides password (via header, cookie, or basic auth)
2. Password is hashed and compared against stored hash
3. If valid, session ID is generated and stored
4. Session cookie is set with HttpOnly flag
5. Subsequent requests use session ID for authentication

### Authorization Model

- **Users**: Individual accounts with passwords
- **Groups**: Collections of users
- **Volumes**: Resources with permissions
- **Permissions**: Fine-grained access control per user/group per volume
  - `r` - Read (list, view)
  - `w` - Write (upload)
  - `m` - Move
  - `d` - Delete
  - `a` - Admin
  - `g` - Get (download without listing)

### Database Schema

#### Users Table
```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username TEXT UNIQUE NOT NULL,
    password_hash TEXT NOT NULL,
    created_at INTEGER NOT NULL
);
```

#### Sessions Table
```sql
CREATE TABLE sessions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username TEXT NOT NULL,
    session_id TEXT UNIQUE NOT NULL,
    created_at INTEGER NOT NULL,
    expires_at INTEGER NOT NULL
);
```

#### Groups Table
```sql
CREATE TABLE groups (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT UNIQUE NOT NULL
);
```

#### User Groups Table
```sql
CREATE TABLE user_groups (
    user_id INTEGER NOT NULL,
    group_id INTEGER NOT NULL,
    PRIMARY KEY (user_id, group_id)
);
```

#### Volumes Table
```sql
CREATE TABLE volumes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT UNIQUE NOT NULL,
    path TEXT NOT NULL
);
```

#### Permissions Table
```sql
CREATE TABLE permissions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    volume_id INTEGER NOT NULL,
    user_id INTEGER,
    group_id INTEGER,
    can_read BOOLEAN DEFAULT 0,
    can_write BOOLEAN DEFAULT 0,
    can_move BOOLEAN DEFAULT 0,
    can_delete BOOLEAN DEFAULT 0,
    can_admin BOOLEAN DEFAULT 0,
    can_get BOOLEAN DEFAULT 0
);
```

## Usage

### Setup

```bash
# Install dependencies
go mod download

# Generate sqlc code
sqlc generate

# Run example
go run cmd/example/main.go
```

### Code Example

```go
package main

import (
    "context"
    "log"

    "github.com/example/go-auth-system/internal/auth"
)

func main() {
    // Initialize auth service
    service, err := auth.NewService("auth.db")
    if err != nil {
        log.Fatal(err)
    }
    defer service.Close()

    ctx := context.Background()

    // Create user
    err = service.CreateUser(ctx, "alice", "secure-password")
    if err != nil {
        log.Fatal(err)
    }

    // Authenticate user
    sessionID, err := service.Authenticate(ctx, "alice", "secure-password")
    if err != nil {
        log.Fatal(err)
    }

    // Get username from session
    username, err := service.GetUsernameFromSession(ctx, sessionID)
    if err != nil {
        log.Fatal(err)
    }

    log.Printf("Authenticated user: %s", username)

    // Check permissions
    perms, err := service.GetUserPermissions(ctx, username, "my-volume")
    if err != nil {
        log.Fatal(err)
    }

    if perms.CanRead {
        log.Println("User can read from volume")
    }
}
```

## Security Features

1. **Argon2id Password Hashing**: Industry-standard password hashing with recommended parameters
2. **Cryptographically Secure Session IDs**: Using crypto/rand for session generation
3. **HttpOnly Cookies**: Session cookies not accessible via JavaScript
4. **Secure Cookie Flag**: Enabled for HTTPS connections
5. **Session Expiration**: Configurable session timeout
6. **Permission Caching**: Fast permission lookups

## Comparison to copyparty

This implementation follows copyparty's design patterns:

| Feature | copyparty | This Implementation |
|---------|-----------|-------------------|
| Password Hashing | Argon2id (configurable) | Argon2id |
| Session Storage | SQLite | SQLite |
| Session ID | Base64(random bytes) | Hex(random bytes) |
| Permissions | String codes (r,w,m,d,a) | Boolean flags |
| Groups | Dict-based | SQLite-based |
| Cookie Auth | Yes (cppwd/cppws) | Yes (session_id) |
| Volume-based ACL | Yes | Yes |
